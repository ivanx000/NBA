# Credits

Tip-Off is an unofficial fan project, not affiliated with the NBA or any team. It uses team city
and nickname text and colors only: no league or team logos, wordmarks, or real player likenesses.

## 3D player and animations
- Player model, rig and animations: generated for this project with [Meshy](https://www.meshy.ai)
  (image to 3D, auto-rigging, Text to Motion, and clips from Meshy's animation library), under
  Meshy's terms for generated assets. The base character image was generated with ChatGPT.
- Jersey colors and lettering are drawn in code from `shared/teams.json`.

## Environment
- The arena, platforms, hoop, ball and effects are generated in code (three.js); no third-party
  textures, HDRIs or models are used.

## Fonts (SIL Open Font License 1.1, via Google Fonts)
- Archivo (Omnibus-Type)
- JetBrains Mono (JetBrains)
- Oswald (Vernon Adams), for jersey lettering

## Software
- three.js, React Three Fiber and drei (MIT), postprocessing (Zlib), GSAP (Standard "No Charge"
  license), Next.js (MIT), and the other packages in `web/package.json`.

## Data
- Schedules, scores and box scores from NBA.com's public stats and data endpoints.
